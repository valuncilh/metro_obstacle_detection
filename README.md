# Обнаружение посторонних объектов в тоннеле метро

Проект для обнаружения препятствий перед беспилотным поездом метрополитена по данным 3D-лидара.

## Задача

По потоку облаков точек от 3D-лидара нужно определять:

- есть ли впереди препятствие;
- расстояние до ближайшего препятствия.

## Окружение

- ОС: Ubuntu 22.04
- ROS 2: Humble
- Docker: обязателен для финального запуска
- Данные: ROS 2 bag-файлы
